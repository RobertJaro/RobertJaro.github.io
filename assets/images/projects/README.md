# Project figures

Figures are selected from the research papers and official project resources linked in the project pages. They are original scientific results, not generated illustrations.

Each `*-sources.json` file records the source publication or project, figure number, source/download URL, known license, and any cropping or resizing. Captions provide reader-facing attribution. Thumbnails may use a representative panel; the project page contains the labeled figure and explains its context.

Keep panel labels, legends, color scales, and scientific content intact when updating these assets. An arXiv distribution license is not a Creative Commons reuse license; consult the recorded source for the applicable rights. No uniform license is asserted for this directory.
